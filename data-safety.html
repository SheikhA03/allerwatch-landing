Not declared

Audio/voice recordings. AllerWatch uses Android's system speech recognizer for voice meal-logging, but the app never receives, stores, or transmits the raw audio itself — only the transcribed text comes back to the app. Per Play's guidance this pass-through case doesn't require an Audio declaration. This is a judgment call, not a certainty — flag it to a lawyer for a second opinion if needed.

Precise location. A location permission exists in unused template code inherited from the kit; no AllerWatch screen requests it, so nothing to declare.
